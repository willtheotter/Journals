Week 1 — September 5, 2026

Introduction to Algorithms & Pseudocode

This week's module covered foundational concepts including algorithm definitions, Euclid's algorithm for GCD calculation, pseudocode notation, and important problem types such as sorting, searching, and graph problems. We also reviewed fundamental data structures (arrays, linked lists, trees, graphs) and began exploring the algorithm analysis framework.

Key learnings:

  • Euclid's Algorithm: gcd(m,n) = gcd(n, m mod n). Example: gcd(6,10) = gcd(6,4) = gcd(4,2) = gcd(2,0) = 2.
  • Pseudocode: Practiced identifying basic operations like comparisons (<) and arithmetic (+) within loops.
  • Graph Representations: Reviewed adjacency matrices and adjacency lists for weighted vs. unweighted graphs.
  • Puzzles: Solved the fake coin puzzle (9 coins, 2 weighings) and the choosing balls in the dark puzzle (best case: 2, worst case: 13).

Topics: Algorithms · Euclid's GCD · Pseudocode · Graphs · Problem Types
